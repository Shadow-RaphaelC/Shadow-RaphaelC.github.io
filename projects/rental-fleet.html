Rental-Fleet

In progress En cours

Rental-Fleet is a vehicle rental system made of three separate apps: a REST API that manages the fleet, an admin dashboard that talks to the API from the browser, and a public rental website in PHP that uses the same API from the server.

Rental-Fleet est un système de location de véhicules composé de trois applications distinctes : une API REST qui gère la flotte, un tableau de bord d'administration qui communique avec l'API depuis le navigateur, et un site de location public en PHP qui utilise la même API côté serveur.

How it fits together

Comment ça fonctionne

  • api.rental-fleet.com: the Node.js REST API, the only part that touches the data
  • admin.rental-fleet.com: admin dashboard in JavaScript, calls the API with Fetch
  • budget-location.ca: public rental site in PHP, calls the API with cURL
  • api.rental-fleet.com : l'API REST en Node.js, la seule partie qui accède aux données
  • admin.rental-fleet.com : tableau de bord d'administration en JavaScript, appelle l'API avec Fetch
  • budget-location.ca : site de location public en PHP, appelle l'API avec cURL
